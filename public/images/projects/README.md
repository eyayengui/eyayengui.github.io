# Project images

Put real screenshots here, then reference them in `src/data/projects.ts`
(paths are relative to `public/`), for example:

```ts
image: 'images/projects/saldae/cover.webp',
gallery: ['images/projects/my-project/dashboard.webp', 'images/projects/my-project/registry.webp'],
architecture: 'images/projects/my-project/architecture.webp',
video: 'images/projects/my-project/demo.mp4', // or a YouTube embed URL
```

Recommended: 1600×1000 px (16:10), WebP, < 400 KB each.
Until an image is set, the site shows a clearly marked placeholder.
